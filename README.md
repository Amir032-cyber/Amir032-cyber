## About

I am a security engineer based in Burkina Faso, working across Java, distributed systems, and resilient software design. My projects explore practical ways to make developer workflows, infrastructure, and security tooling more reliable, observable, and easier to operate.

I am part of **Digital Leaders Academy Ltd** and use open source as a way to learn in public, share working ideas, and turn complex engineering problems into usable systems.

## What I work on

My current focus is the intersection of security engineering, AI-assisted development, CI/CD optimization, and fault-tolerant systems. I enjoy working on tools that reduce operational friction: selecting the right tests, orchestrating security workflows, connecting services, and keeping systems useful under failure.

## Security and resilience, specifically

- Designing software around failure isolation, graceful degradation, and recovery paths.
- Exploring security tooling that combines a fast systems core with modular services.
- Building CI/CD workflows that use change-aware test selection to improve feedback speed and resource efficiency.
- Treating observability, repeatability, and operational clarity as part of the product—not as afterthoughts.
- Learning by turning difficult concepts into documented, runnable experiments.

## How I work

- **Reliability is a feature.** A system is not finished when the happy path works; it is finished when failure behavior is understandable.
- **Prefer useful experiments.** A small runnable prototype often reveals more than a long theoretical debate.
- **Make complexity visible.** Clear architecture, documentation, and operational signals help teams make better decisions.
- **Keep learning in public.** Open source turns implementation details into feedback, context, and shared knowledge.
- **Build with purpose.** Security and resilience should improve the experience of the people who depend on the system.
